# python-ai-basics

Introduction to Python, NumPy, Pandas, and Data Visualization for AI 

Dataset Description

This experiment uses the Iris dataset, a classic dataset in machine learning education. It is small, clean, and directly available from Scikit-learn, so students can focus on learning the tools instead of downloading or cleaning a complicated file.

The dataset contains 150 flower samples from three species:

1.Setosa
2.Versicolor
3.Virginica

Each sample has four numerical features:

1.Sepal length
2.Sepal width
3.Petal length
4.Petal width
